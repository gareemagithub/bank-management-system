A secure and efficient net banking application that allows users to create accounts, perform transactions, and view account statements. The application ensures reliability and data integrity for seamless banking operations.

Features:-  
Account Creation: Users can securely create accounts with unique credentials.
Transactions: Supports deposit and withdrawal of funds with proper validations.
View Account Statements: Allows users to view their transaction history and account balance.
Secure and Efficient: Data is securely stored and managed in the backend with MySQL to ensure consistency and reliability.

Technologies Used:-  
Java (Swing, AWT): Frontend user interface design and interaction.
MySQL: Backend database for storing user details, transaction history, and account information.
JDBC: For connecting the Java application to the MySQL database.
